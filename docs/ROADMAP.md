## Direction

Stay a **small native GNOME downloader**: paste Spotify links, get organised files, play them in your own music library. Prefer reliable Flatpak installs and calm Adwaita UI over becoming a full media suite.

## Themes

1. **Download reliability** — clearer errors, solid retries, healthy backup sources  
2. **Operator UX** — Flatpak-first installs, honest docs, predictable Preferences  
3. **Library fit** — folder templates and metadata that work with common music library players  
4. **Project hygiene** — SemVer app releases, focused PRs, brand consistency with sibling projects

- Windows / macOS packaging in this fork
- Replacing the upstream spotDL CLI project
